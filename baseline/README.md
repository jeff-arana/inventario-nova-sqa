# Fotografía conceptual de la aplicación antes de SQA

El repositorio MIT `DMS-ranil/react-mysql-crud-template` se usó como referencia pública de arquitectura: React, Express, MySQL y CRUD de productos. Esta carpeta NO afirma reproducir un commit de ese repositorio ni representa métricas auditadas de su código. El archivo siguiente se creó para reproducir, de manera didáctica, un defecto de validación previo al control SQA y compararlo con el módulo implementado. Las cifras de SonarCloud de las capturas son ejemplos ilustrativos, no una medición del repositorio original.
