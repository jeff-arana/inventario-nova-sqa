# Bibliografía y documentación técnica

1. GitHub Docs. *About protected branches*. https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches
2. GitHub Docs. *Status checks*. https://docs.github.com/en/pull-requests/reference/status-checks
3. Jest. *Configuration: coverageThreshold*. https://jestjs.io/docs/configuration
4. React. *React documentation*. https://react.dev/
5. Express. *Express guide*. https://expressjs.com/
6. MySQL. *MySQL 8.4 Reference Manual*. https://dev.mysql.com/doc/refman/8.4/en/
7. GitHub. *GitHub Actions documentation*. https://docs.github.com/actions
8. SonarSource. *SonarQube Cloud documentation*. https://docs.sonarsource.com/sonarqube-cloud/
9. ISO/IEC. *ISO/IEC 25010, Systems and software quality models* (referencia conceptual).
10. IEEE. *IEEE 730, Software Quality Assurance Processes* (referencia conceptual).

Las referencias oficiales se consultan para criterios de herramientas, control de ramas y fundamentos de calidad. Las mediciones del producto, cuando se reporten, deben provenir de ejecuciones específicas del código correspondiente.
